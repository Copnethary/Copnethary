# BeaconGuard（信标保护）

Paper 26.3 插件，可与 TeleportBeacon（传送信标）一起使用，也支持普通原版信标。

构建：`JAVA_HOME=<JDK 25> mvn -q package` → `target/BeaconGuard.jar`
部署：复制到 `plugins/` 后重启。数据：`plugins/BeaconGuard/regions.yml`，配置：`config.yml`。

## 玩法
1. 放下信标（传送信标或原版信标都可以），聊天栏会出现：
   `是否保护此地标？ [保护] [忽略]`
2. 点 **[保护]** 后，以信标为中心 **50 格**（可配置）内：
   - 普通玩家无法破坏任何方块（镐子、徒手、其它工具都不行），只有管理员（`beaconguard.admin`，默认 OP）可以；
   - 苦力怕、TNT、TNT 矿车、恶魂火球、凋灵、末影龙、末影水晶、床/重生锚爆炸都炸不坏区内方块；
   - 末影人搬方块、劫掠兽/凋灵破坏、僵尸破门、蠹虫等无效；
   - 火烧不掉方块；区外的活塞、液体、发射器无法破坏区内方块；
   - 画、物品展示框、盔甲架也受保护；耕地/海龟蛋不会被踩坏；告示牌不能被改写；
   - 普通玩家也不能用桶舀走区内的水/岩浆，不能用斧子去皮、锄地等改动方块。
3. 中心信标被管理员挖掉后，保护自动取消（可在配置里关闭）。

## 指令（`/guard`，别名 `/bg`、`/保护`）
| 指令 | 说明 |
|---|---|
| `/guard protect` | 保护你所在的位置 |
| `/guard protect <x> <y> <z> [世界]` | 保护指定坐标（支持 `~` 相对坐标） |
| `/guard flag <开关> <allow\|deny> [编号]` | 修改保护区规则 |
| `/guard flags` | 查看所有开关 |
| `/guard info [编号]` | 查看保护区，可直接点击切换开关 |
| `/guard list [all]` | 列出自己的（管理员可 all）保护区 |
| `/guard remove [编号]` | 取消保护 |
| `/guard radius <半径> [编号]` | 管理员：修改某个保护区的半径 |
| `/guard tp <编号>` / `/guard reload` | 管理员 |

不写编号时，默认是你当前站着的那个保护区。只有保护区主人或管理员能改开关/取消。

### 开关
| 开关 | 含义 | 默认 |
|---|---|---|
| `pvp` | 玩家互相攻击（含弓箭、三叉戟、药水、火焰附加） | 允许 |
| `fire-spread` | 火焰蔓延、点火（无论开关如何，火都烧不掉方块） | 允许 |
| `mob-spawn` | 怪物自然生成（刷怪笼、刷怪蛋不受影响） | 允许 |
| `mob-damage` | 怪物伤害玩家 | 允许 |
| `place` | 普通玩家放置方块、倒水倒岩浆、挂画 | 允许 |
| `interact` | 普通玩家使用箱子、门、按钮、拉杆、展示框等（信标不受影响） | 允许 |

例：`/guard flag pvp deny`、`/guard flag fire-spread deny`。

## 与传送信标的配合
- 放下传送信标时，先显示传送信标自己的提示，再弹出保护提示。
- 保护区内普通玩家挖不掉传送信标（包括自己放的），需要管理员来挖；管理员挖掉中心信标时，传送点和保护区会一起被移除。
- 右键信标打开传送菜单不受 `interact` 开关影响。

## 限制（config.yml）
- `max-regions-per-player`：普通玩家最多几个保护区（默认 3）。
- `allow-overlap`：是否允许和别人的保护区重叠（默认不允许）。
- `shape`：`square` 正方形 / `circle` 圆形；`height`：`full` 整列保护（防止从地下挖进来）或上下格数。
